# Visual prompts for 321AI

The repository already ships real product screenshots and brand assets. These prompts are for generating additional editorial / campaign visuals when a designed asset is needed.

## Hero / README banner (16:9, 1600×900)

> Premium dark editorial tech poster for an AI API marketplace. Floating layers of translucent data streams, small hexagonal nodes and a subtle globe made of light particles. A six-dot constellation mark on the left, generous negative space on the right. Deep ink background (#0b0d12), ice-blue and warm amber accents, cinematic soft glow, crisp vector-like forms. No text, no letters, no logos, no UI screenshots. Sophisticated, expensive, calm — not a crypto ad.

## Marketplace illustration (16:9, 1600×900)

> Isometric marketplace of AI model suppliers: many small server islands connected by luminous routes to one central gateway ring. Each island has a tiny price tag and a health pulse. Dark navy background, thin cyan lines, selective orange highlights, clean 3D vector style, lots of breathing room, no text, no logos.

## Social preview / OG card (1280×640)

> Minimal premium brand card: six-dot constellation on a deep ink field, a single thin orbital arc, soft champagne spotlight from the top right. Large empty area for typography on the right; no text or letters in the image. Modern infrastructure brand, understated luxury, crisp edges, high contrast, no stock-photo people.

## Avatar / profile mark (1:1, 512×512)

> A single six-dot 3-2-1 constellation mark, white dots on a near-black background, perfectly centered, bold geometric circles with tiny gaps, no text, no border, no gradient background, high contrast, recognizable at 24px.

## Editorial blog illustration (16:9)

> Abstract routing diagram: one bright request line splitting into several candidate paths, each path with a different price/health signal, one path chosen and highlighted. Dark technical canvas, fine grid, cyan and amber accents, precise vector geometry, no text. Feels like a premium developer tool, not a generic AI brain.

## Usage notes

- Keep text out of generated images; overlay real typography in Figma/Canva.
- Use the real 321AI six-dot mark only if the generator can preserve its geometry; otherwise leave the mark area empty and composite the official SVG/PNG.
- Avoid fake dashboards, fake customer logos and fake metrics. The screenshots in this repo are real product captures.
